# lpvid resources

Version: 0.2

This directory documents the external resources that lpvid needs. Source code
and large resources are distributed separately: the git repository stays small,
and models or databases are placed here, or anywhere else on disk, and
referenced from `config/local.yaml`.

The complete file-level inventory is
[`RESOURCE_MANIFEST.tsv`](RESOURCE_MANIFEST.tsv). Its columns are:

| Column | Meaning |
|---|---|
| `category` | Resource group |
| `item` | File name or directory item |
| `required` | `required`, `optional` or `generated` |
| `install_path` | Where the file must live, relative to the repository root |
| `purpose` | What the workflow uses it for |
| `size_bytes` | Size in bytes; for directories, the sum of contained files |
| `sha256` | SHA-256 when known at packaging time; empty for very large external items |
| `source_hint` | Provenance: bundled in the repository, shipped in the resource package, or the releasing channel |
| `notes` | Acquisition or verification notes, for example `verify_after_download` |

The manifest for the final release is the authoritative source for file counts,
sizes and checksums. This document intentionally does not duplicate those
statistics.

## Required layout

```text
resources/
  phylo/
    backbone_dir/<supergroup>/{*.nwk,*.fas}
    adapter_dir/<supergroup>/{adapter_config.json,adapter_model.safetensors,...}
    taxonomy/<supergroup>.csv
  rdrp/
    rdrp_reference.dmnd
    rdrp_reference.fas
    rdrp_reference.csv
  models/
    rdrp_detector/
    lucaphylo/
    classifier/
      pipeline/
      encoder/
      model/
  blastdb/refseq_protein/
    refseq_protein.dmnd
    TAXID_viruses.txt
    TAXID_cellular.txt
  rrna/
    silva_ssu.*
    silva_lsu.*
```

Install paths in the manifest are always relative to the repository root, and
`config/local.example.yaml` uses the same relative paths. If you keep resources
elsewhere, point `config/local.yaml` at the absolute locations instead.

## Resource groups

| Group | Content | Delivered as |
|---|---|---|
| Report assets | Offline chart and table libraries for HTML reports | bundled in git |
| Viewer assets | PDF and vector export libraries for the tree explorer | bundled in git |
| Risk catalog | Reference lists used for report notices | bundled in git |
| Supergroup mapping | Legacy to current supergroup name mapping | bundled in git |
| Phylogenetic backbone trees | Curated backbone alignments, trees and taxonomy tables | bundled in git |
| Phylogenetic adapters | LoRA placement adapters for 24 supergroups | Zenodo resource record |
| RdRP reference | Reference database, sequences and labels | bundled in git |
| RdRP detector | Detection model weights and runtime files | Zenodo resource record |
| Phylogenetic model | LucaPhylo base model and classifier encoder | Zenodo resource record |
| Classification model | Launcher, labels and runtime model files | bundled in git |
| Classification encoder | Encoder checkpoint used by the classifier | Zenodo resource record |
| Protein reference database | RefSeq protein DIAMOND database | separate distribution (large) |
| RefSeq taxid whitelists | Viral and cellular taxid lists used by the prefilter | bundled in git |
| rRNA indexes | SILVA SSU and LSU bowtie2 indexes | Zenodo resource record |
| Prepared assets | Local reference assets built under `assets/` | generated by `lpvid prepare` |

## Checksums and verification

- Files bundled in git carry SHA-256 values in the manifest.
- The downloadable resource archives and their SHA-256 values are listed in
  [`EXTERNAL_RESOURCES.md`](EXTERNAL_RESOURCES.md).
- Individual files inside the archives are marked `verify_after_download` in the
  manifest; the archive checksum is the authoritative integrity check.
- The workflow validates readiness with `lpvid doctor`; it checks that each
  configured path exists but does not re-hash large databases.
- `lpvid prepare` validates the local backbone trees, taxonomy tables and
  adapters, then builds the prepared reference assets under `assets/`. It does
  not download anything.

## Acquisition notes

- **Bundled resources**: `resources/rdrp/`, `resources/phylo/backbone_dir/`,
  `resources/phylo/taxonomy/`, the classifier launcher, labels and runtime model
  files, and the two RefSeq taxid whitelists are included in this repository.
  Their SHA-256 values are recorded in the manifest.
- **Phylogenetic adapters**: `resources/phylo/adapter_dir/` contains the 24 LoRA
  placement adapters (about 545 MiB as a group).
- **External model resources**: `models/rdrp_detector`, `models/lucaphylo` and
  `models/classifier/encoder` are distributed through the Zenodo resource
  record; archive names, sizes and checksums are listed in
  [`EXTERNAL_RESOURCES.md`](EXTERNAL_RESOURCES.md).
- **Protein reference database**: the RefSeq protein DIAMOND database is built
  from NCBI RefSeq proteins; the two bundled `TAXID_*.txt` whitelists accompany
  it.
- **SILVA SSU and LSU**: bowtie2 indexes built from the SILVA ribosomal RNA
  database (index files share a prefix, for example `resources/rrna/silva_ssu`).
- **Prepared assets**: not a download; `lpvid prepare` regenerates them from the
  phylogenetic backbone package.

After placing resources, run from the repository root:

```bash
lpvid doctor
lpvid prepare
```
